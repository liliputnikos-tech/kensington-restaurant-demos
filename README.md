# Kensington restaurant demo sites

One-page demo websites prepared for ten independent cafés, restaurants and pubs in Kensington, Chelsea and Earl’s Court, London.

Live: https://liliputnikos-tech.github.io/kensington-restaurant-demos/

These are demos, not the official websites of the businesses shown, and they are not affiliated with or endorsed by them. Pages carry a `noindex` tag so they stay out of search results.

## Layout

- `index.html`: overview linking every demo
- `<slug>/index.html`, `style.css`, `favicon.svg`: one static site per folder, no build step
- `<slug>/img/`, `<slug>/fonts/`, `assets/`: photos and self-hosted fonts, generated by `tools/build_assets.py` from the sources in `assets.json` (run by the `assets` GitHub Actions workflow)

Photos are from Wikimedia Commons (CC0, public domain, CC BY, CC BY-SA) and are credited on each page; food photos are illustrative. Fonts are from Google Fonts (SIL Open Font License).
